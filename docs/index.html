Data automation · case study

Screen GrabTurning a folder of lab workbooks into report-ready tables, in one run

In 2023 I worked on a validation study of two reporter-gene assays used to detect endocrine disruptors. Every experiment produced one Excel workbook per run, and the study report needed the same key numbers from each one, laid out the same way. Instead of copying cells and taking screenshots by hand, I wrote a Python script that opens every workbook in a folder, reads the right cells and exports one clean PNG table per chemical.

The biology in brief

Two receptors, three questions

Both assays use human cells that make light (luciferase) when a hormone receptor is switched on. A transactivation assay (TA) measures that light after 16 to 24 hours of exposure to a chemical.

GRTA

Glucocorticoid receptor

The receptor for cortisol, the stress hormone. It controls inflammation, sugar metabolism and the response to stress. Reference agonist: a synthetic glucocorticoid such as dexamethasone.

RARTA

Retinoic acid receptor

The receptor for retinoic acid, made from vitamin A. It guides embryo development and cell differentiation. Reference agonist: a synthetic retinoid such as TTNPB.

AGO · agonist

The chemical alone, at 7 doses. Light is expressed as a percentage of the reference agonist’s maximum. Basal is the light of untreated wells; the induction factor is how many times brighter the reference makes the cells.

ANT · antagonist

The chemical plus the reference agonist at the dose giving about 80 % of its maximum (Ref80). If the chemical blocks the receptor, the light falls below that 80 % line.

INT · interference

The same co-exposure with the reference at full strength. A true competitor loses ground against a full dose; a chemical that harms the cells or the light reaction keeps lowering the signal.

Viability

For every dose the workbook also holds a viability reading. A drop in light only counts if the cells are still alive at that dose.

Inside one run

One 96-well plate, two chemicals

Each run tests two chemicals on the same plate: the top one in rows A–D, the bottom one in rows E–H, each at 7 concentrations in 4 replicate wells. These 28 wells are exactly the 7 × 4 block the script cuts out of the workbook. Hover a well to see what it contains.

    Inside the script

    Four ideas do all the work

    Loop over a whole folder

    pathlib finds every workbook, so a new batch of runs only needs to be dropped in the folder.

    mydir = Path('.../GRTA/PHASE_2/ago')
for file in mydir.glob('*.xlsx'):
    df = pd.read_excel(file, sheet_name='Luminescence')

    Read single cells by position

    The run template never changes, so each field sits at a fixed address. iat[row, col] picks it directly.

    date         = df.iat[2, 4]    # cell E4
molecule_top = df.iat[13, 4]   # cell E15
mode         = df.iat[13, 6]   # cell G15
IFmean       = df.iat[18, 4]   # cell E20

    Cut out a data block

    Skip to the right row, keep 7 rows, and select only the normalised columns. The raw luminescence columns stay behind.

    pd.read_excel(file, sheet_name='Viability',
    skiprows=29, nrows=7,
    usecols='D,L:O, P, Q, S')
# → Conc(M), norm1..4, mean%, sd%, CV%

    Render, name and skip

    Tables are laid out in a grid and saved under a name built from the run's own metadata. Empty bottom halves are skipped.

    names = [molecule, mode, run, date]
export_png(grid, filename='_'.join(names) + '.png')

if molecule_bot == "no compound": continue

    Looking back

    What I would change today

    My notes at the time

    • Bokeh is built for interactive pages, so exporting static PNGs through a headless browser was slow.
    • Some pandas calls (set_axis(..., inplace=True)) were already deprecated.
    • Ref80 for antagonist runs and Ref100 for interference runs were still to be added.

    A single configurable script

    The six copies differ only in a folder, a file extension and a few cell addresses. Today I would keep those in one table and write the extraction once.

    LAYOUT = {
  'AGO': dict(extra={}),
  'ANT': dict(extra={'Ref80': 'E21:F21', 'Coexpo': 'E11'}),
  'INT': dict(extra={'Coexpo': 'E11'}),
}
for assay, ext in [('GRTA', 'xlsx'), ('RARTA', 'xlsm')]:
    for mode, cfg in LAYOUT.items():
        for wb in (ROOT / assay / mode).glob(f'*.{ext}'):
            export_card(read_run(wb, cfg))  # matplotlib table

    What this project shows

    Skills behind the tool

    Automating the boring part

    Spotting a repetitive manual task in a team workflow and replacing it with a script colleagues could rerun.

    Reading messy sources

    Pulling structured data out of human-formatted spreadsheets with fixed layouts, mixed types and empty slots.

    Consistent outputs

    Same table, same formats (%, scientific notation) and a predictable file name for every run, ready for the report.

    Honest about limits

    Writing down performance problems and missing fields in the code itself, so the next person knows where to start.
